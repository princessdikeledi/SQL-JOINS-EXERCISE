# SQL JOIN Practice

## 📌 Overview

This project contains SQL exercises focused on using JOINs to combine data from multiple tables.

The exercises were completed using Databricks SQL and are designed to strengthen my understanding of how related data can be connected and analysed across different tables.

## 🎯 Objectives

- Understand how SQL JOINs work
- Combine data from multiple tables
- Identify relationships between tables
- Retrieve matching and non-matching records
- Practice using table aliases
- Improve my SQL querying and data analysis skills

## 🔗 JOINs Covered

### INNER JOIN
Returns only records that have matching values in both tables.

### LEFT JOIN
Returns all records from the left table and matching records from the right table.

### RIGHT JOIN
Returns all records from the right table and matching records from the left table.

### FULL OUTER JOIN
Returns all records from both tables, including records that do not have a match.
